Rust：服务器读取并解析数据包头部

let head = loop {
    match packet::try_parse_head(&mut self.read_buf) {
        Ok(Some(x)) => break x,
        Err(e) => log::error!("{}", e),
        Ok(None) => {
            log::debug!("Waiting for reading data...");
        }
    }

    let read_bytes_num = read_from_stream(&mut self.stream, &mut self.read_buf)?;
    if read_bytes_num == 0 {
        if self.read_buf.is_empty() {
            return Ok(None);
        } else {
            bail!("Connection closed by peer. Incomplete data.");
        }
    }
};

JavaScript：学习记录筛选与主题切换

const input = document.getElementById('log-filter');
const articles = Array.from(document.querySelectorAll('#learn-log article'));

input.addEventListener('input', () => {
    const q = input.value.trim().toLowerCase();
    articles.forEach((article) => {
        article.hidden = q !== '' && !article.textContent.toLowerCase().includes(q);
    });
});

  • 我负责什么：编写并维护前端开发的 Agent 提示词，把庞大的 AGENTS.md 拆成 /docs 下的模块化规则文件；协调前端功能与 AI 生成代码的调试，处理兼容性与边界情况。
  • 用了什么技术：原生 HTML/CSS/JavaScript 前端，单文件，localStorage 存数据，响应式布局。
  • 最大困难：AI 生成代码前后不一致、响应式布局在窄屏下错位；通过小步验证、模块化提示词和媒体查询逐步解决。
  • 作品链接：web-lost-n-found-test

ESP32 RWR 告警器

  • 解决什么问题：用 ESP32 复刻《War Thunder》里的 RWR（雷达告警接收机）显示。
  • 我负责什么：独立完成硬件选型、电路连接、固件开发与调试。
  • 用了什么技术：C++/ESP32、FreeRTOS 多线程、GPIO/I2C/SPI。
  • 最大困难：外部电磁干扰导致传感器读数跳变；通过金属屏蔽壳、接地优化、软件滤波与互斥锁解决。
  • 作品链接：esp32-rwr-alert
